    CORE CONCEPT
    
        
    Mutability is about the object
    
        
    It means whether an object’s contents can change after it is created—not whether a variable can be
          reassigned.
    
      
    
      
    
      
    Important edge case: a tuple cannot replace one of its references, but a mutable
        object inside it still can change: data = ([1, 2], 10); data[0].append(3).
