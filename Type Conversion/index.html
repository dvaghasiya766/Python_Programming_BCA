📚 What is Type Conversion?

Type conversion is the process of converting a value from one data type to another data type.

a = "100"
b = int(a)
print(b)

Here, the string "100" is converted into an integer using int().

🔄 Common Type Conversion Functions

Function Purpose Example Result
int() Convert to integer int("25") 25
float() Convert to float float("25.5") 25.5
str() Convert to string str(25) "25"
bool() Convert to Boolean bool(1) True

⚠️ Important Concepts

  • input() always returns a string.
  • Use int() when an integer is required.
  • Use float() when a decimal number is required.
  • Use str() to convert a value into text.
  • Use bool() to convert a value into True or False.
  • Not every value can be converted into every data type.
