💡 Remember

Python strings are immutable. String methods do not change the original string. Instead, they generally return a new string. 

s = "python"

result = s.upper()

print(s)
print(result)

Output:

python
PYTHON

📖 Common String Methods

Category Method Description Example
🔤 Case upper() Converts string to uppercase. "hello".upper() → HELLO
🔤 Case lower() Converts string to lowercase. "HELLO".lower() → hello
🔤 Case title() Capitalizes the first letter of each word. "hello world".title() → Hello World
🔤 Case capitalize() Capitalizes the first character. "python".capitalize() → Python
🔤 Case swapcase() Swaps uppercase and lowercase characters. "PyThOn".swapcase()
🔍 Search find() Returns the first occurrence index or -1. "banana".find("a") → 1
🔍 Search rfind() Returns the last occurrence index. "banana".rfind("a") → 5
🔍 Search index() Returns the index of the first occurrence. "python".index("t") → 2
🔍 Search rindex() Returns the last occurrence index. "banana".rindex("a") → 5
📏 Checking startswith() Checks whether a string starts with a value. "Python".startswith("Py") → True
📏 Checking endswith() Checks whether a string ends with a value. "Python".endswith("on") → True
🔄 Modify replace() Replaces one substring with another. "a-b".replace("-", ":") → a:b
🔄 Modify strip() Removes leading and trailing whitespace. " hi ".strip() → hi
🔄 Modify lstrip() Removes whitespace from the left. " hi".lstrip() → hi
🔄 Modify rstrip() Removes whitespace from the right. "hi ".rstrip() → hi
✂️ Split split() Splits a string into a list. "a,b".split(",")
✂️ Split rsplit() Splits from the right side. "a,b,c".rsplit(",",1)
✂️ Join join() Joins elements using a separator. "-".join(["A","B"]) → A-B
🔢 Validation isdigit() Checks whether all characters are digits. "123".isdigit() → True
🔢 Validation isalpha() Checks whether all characters are letters. "Python".isalpha() → True
🔢 Validation isalnum() Checks whether characters are letters or digits. "Python123".isalnum() → True
🔢 Validation isspace() Checks whether all characters are whitespace. " ".isspace() → True
🔍 Others count() Counts occurrences of a substring. "banana".count("a") → 3
🔍 Others zfill() Pads a string with zeros. "5".zfill(3) → 005
