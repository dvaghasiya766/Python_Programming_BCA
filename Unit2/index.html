1. Operators

Operators are special symbols or keywords used to perform operations on one or more values.

The values on which an operator works are called operands. 

2 + 3

Here, 2 and 3 are operands, while + is the operator.

1. Arithmetic Mathematical calculations
2. Comparison Compare values
3. Logical Combine conditions
4. Bitwise Perform operations on bits
5. Assignment Assign or update values
6. Identity Compare object identity
7. Membership Test whether a value exists

Arithmetic Operators

Arithmetic operators are used to perform mathematical calculations.

Comparison Operators

Comparison operators compare two values and return a Boolean result: True or False.

Operator Description Example Result

Logical Operators

Logical operators are used to combine or reverse Boolean expressions.

Operator Description Example Result
and True when both expressions are True 5 == 2 and 5 > 2 False
or True when at least one expression is True 5 == 2 or 5 > 2 True
not Reverses the Boolean result not(5 == 2) True

Bitwise Operators

Bitwise operators perform operations on the binary representation of integer values.

Operator Name Description Example Result
& AND Sets a bit to 1 when both bits are 1. 5 & 2 0
| OR Sets a bit to 1 when at least one bit is 1. 5 | 2 7
^ XOR Sets a bit to 1 when the bits are different. 5 ^ 2 7
~ NOT Inverts the bits of an integer. ~10 -11
<< Left Shift Shifts bits toward the left. 5 << 2 20
>> Right Shift Shifts bits toward the right. 5 >> 2 1

Identity Operators

Identity operators check whether two variables refer to the same object.

Operator Description Example
is True when both references refer to the same object.

is not True when the references refer to different objects.

Membership Operators

Membership operators test whether a value exists inside a sequence or collection.

Operator Description Example Result

2. String

A string is an immutable sequence of Unicode characters used to store and manipulate text.

Strings can be created using single quotes, double quotes, or triple quotes. 

name = "Python"

message = 'Hello Python'

description = """Python is a
programming language."""

Characteristics of Strings

  • Immutable: A string cannot be changed after creation.
  • Sequence: Characters are ordered and can be accessed using indexing and slicing.
  • Unicode: Python 3 strings support Unicode characters.
  • No Character Data Type: A single character is simply a string containing one character.

String Concatenation

Concatenation joins two or more strings. 

print("Hello" + " World!")
Hello World!

String Repetition

print("Ha" * 3)
HaHaHa

String Indexing

Indexing accesses a character using its zero-based index. 

s = "Python"

print(s[0])
print(s[2])
P
t

String Slicing

Slicing extracts a portion of a string. The start index is inclusive and the end index is exclusive. 

s = "Python"

print(s[1:4])
yth

String Membership

print("Py" in "Python")
True

3. User Input

User input is data provided by a user while a program is running.

Python provides the built-in input() function for receiving input from the user through the console.

Basic Syntax

variable_name = input("Prompt message: ")

Example

name = input("Enter your name: ")

print("Hello", name)
Important: Program execution pauses when input() is called until the user enters data and presses Enter.

4. Type Conversion

Type conversion means converting a value from one data type into another.

Important: input() always returns a string. 
age = input("Enter your age: ")

print(type(age))

If the user enters 20, the value received by the program is "20", which is a string.

Common Conversion Functions

Function Purpose Example
int() Converts to integer. int("123")
float() Converts to floating-point number. float("12.5")
str() Converts to string. str(123)
bool() Converts to Boolean. bool(1)

Example

number = input("Enter a number: ")

number = int(number)

print(number + 10)

5. Comprehension

Comprehension provides a concise way to create new collections from existing iterables.

Common forms include:

  • List Comprehension
  • Set Comprehension
  • Dictionary Comprehension

List Comprehension

squares = [x * x for x in range(1, 6)]

print(squares)
[1, 4, 9, 16, 25]

Comprehensions can make collection-building code shorter and more readable.

6. List

A list is an ordered and mutable collection of elements.

Characteristics

  • Ordered: Elements maintain their sequence.
  • Mutable: Elements can be changed.
  • Duplicates: Duplicate values are allowed.
  • Indexed: Elements use zero-based indexing.
  • Heterogeneous: Different data types can be stored.

Creating a List

numbers = [1, 2, 3, 4, 5]

fruits = ["apple", "banana", "cherry"]

mixed = [10, "Python", 3.14, True]

Accessing List Elements

fruits = ["apple", "banana", "cherry"]

print(fruits[0])
print(fruits[-1])
print(fruits[1:3])
apple
cherry
['banana', 'cherry']

Modifying a List

fruits = ["apple", "banana", "cherry"]

fruits[1] = "blueberry"

fruits.append("orange")

fruits.insert(1, "mango")

fruits.remove("blueberry")

print(fruits)

Important List Methods

Category Methods
Adding append(), extend(), insert()
Removing remove(), pop(), clear()
Searching index(), count()
Reordering sort(), reverse()
Copying copy()
Remember: len(), max(), min(), sum(), sorted(), and list() are built-in functions, not list methods.

A tuple is an ordered and immutable collection of elements.

Characteristics

  • Ordered
  • Immutable
  • Allows duplicate values
  • Supports indexing and slicing
  • Can contain different data types

Creating Tuples

empty_tuple = ()

person = (

8. Set

A set is an unordered collection of unique hashable elements.

  • Duplicate values are automatically removed.
  • Sets do not support indexing or slicing.
  • Sets are mutable, but their individual elements must be hashable.
  • Sets are useful for membership testing and mathematical set operations.

Creating a Set

fruits = {
    "apple",
    "banana",
    "cherry"
}

numbers = {1, 2, 2, 3, 4}

print(numbers)
{1, 2, 3, 4}
Empty Set: {} creates an empty dictionary. Use set() to create an empty set. 
empty_set = set()

Set Methods

Method Description
add() Adds one element.
update() Adds multiple elements.
remove() Removes an element and raises KeyError if absent.
discard() Removes an element if present.
pop() Removes and returns an arbitrary element.
clear() Removes all elements.

Set Operations

Operation Method Operator Description
Union union() | Elements present in either set.
Intersection intersection() & Elements common to both sets.
Difference difference() - Elements in the first set but not the second.
Symmetric Difference symmetric_difference() ^ Elements present in either set, but not both.

9. Dictionary

A dictionary stores data using key:value pairs.

Dictionaries are ordered by insertion order, mutable, and do not allow duplicate keys.

Creating a Dictionary

student = {
    "name": "Dev",
    "age": 20,
    "course": "BCA"
}

print(student)

Accessing Values

print(student["name"])
Dev

Changing Dictionary Values

student["age"] = 21

student["city"] = "Rajkot"

print(student)

Duplicate Keys

data = {
    "year": 1964,
    "year": 2020
}

print(data)
{'year': 2020}
Important: Dictionary keys must be unique. If a key appears more than once, the later value replaces the earlier value.

10. Unpacking with * and **

Python provides * and ** for unpacking values from iterables and dictionaries in appropriate contexts.

Unpacking with *

The * operator can unpack elements from an iterable such as a list, tuple, set, or string. 

x = (1, 2, 3, 4)

print(x)

print(*x)
(1, 2, 3, 4)
1 2 3 4

Dictionary Unpacking with **

The ** operator can unpack key-value pairs from a dictionary. 

dict1 = {
    "name": "Dev",
    "email": "student@example.com"
}

dict2 = {
    "name": "Vijay",
    "age": 20
}

new_dict = {
    **dict1,
    **dict2
}

print(new_dict)
{'name': 'Vijay',
 'email': 'student@example.com',
 'age': 20}
If duplicate keys occur during dictionary unpacking, the value from the later dictionary replaces the earlier value.
