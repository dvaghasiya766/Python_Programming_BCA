📚 What is an Operator?

Operators are special symbols or keywords used to perform operations on one or more values called operands.

10 + 5

Here, 10 and 5 are operands, while + is the operator.

🔢 Types of Operators

1

Arithmetic

Perform mathematical calculations.

2

Comparison

Compare two values.

3

Logical

Combine conditional expressions.

4

Bitwise

Perform operations on individual bits.

5

Assignment

Assign and update values.

6

Identity

Check object identity.

7

Membership

Check whether a value exists.

➕ Arithmetic Operators

Arithmetic operators are used to perform mathematical calculations.

Operator Name Example Result
+ Addition 5 + 2 7
- Subtraction 5 - 2 3
* Multiplication 5 * 2 10
/ Division 5 / 2 2.5
% Modulo 5 % 2 1
** Exponentiation 5 ** 2 25
// Floor Division 5 // 2 2

⚖️ Comparison Operators

Comparison operators compare two values and return True or False.

Operator Description Example
== Equal to 5 == 2 → False
!= Not equal to 5 != 2 → True
> Greater than 5 > 2 → True
< Less than 5 < 2 → False
>= Greater than or equal 5 >= 2 → True
<= Less than or equal 5 <= 2 → False

🧠 Logical Operators

Operator Description Example
and True if both conditions are True True and False → False
or True if at least one condition is True True or False → True
not Reverses the Boolean result not True → False

💻 Bitwise Operators

Bitwise operators perform operations on the binary representation of integers.

Operator Name Example Result
& AND 5 & 2 0
| OR 5 | 2 7
^ XOR 5 ^ 2 7
~ NOT ~10 -11
<< Left Shift 5 << 2 20
>> Right Shift 5 >> 2 1

📝 Assignment Operators

Operator Example Equivalent To
= x = 10 x = 10
+= x += 5 x = x + 5
-= x -= 5 x = x - 5
*= x *= 5 x = x * 5
/= x /= 5 x = x / 5
%= x %= 5 x = x % 5
//= x //= 5 x = x // 5
**= x **= 2 x = x ** 2

🧩 Identity Operators

Identity operators check whether two variables refer to the same object.

a = [1, 2, 3]
b = a

print(a is b)
print(a is not b)

is checks object identity, while is not checks whether two objects are different.

🔍 Membership Operators

Operator Description Example
in Checks whether a value exists "Py" in "Python" → True
not in Checks whether a value does not exist "Java" not in "Python" → True

⚠️ Important Concepts

  • / always performs true division and generally returns a float.
  • // performs floor division.
  • % returns the remainder.
  • == compares values.
  • is checks object identity.
  • in checks membership.
  • and, or, not are logical operators.
  • Bitwise operators work on integer bits.
